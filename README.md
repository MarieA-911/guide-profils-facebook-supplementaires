# Profil Facebook supplémentaire supprimé après le 14 décembre 2026 : que faire ?

Guide gratuit, en français, pour les personnes qui ont reçu l'e-mail de Facebook
*« Your additional Facebook profile will be deleted after December 14, 2026 »*.

- **Ce qui disparaît :** les profils supplémentaires (et leurs informations), après le 14 décembre 2026.
- **Ce qui ne change pas :** le profil principal.
- **Le guide :** 3 questions pour faire le point, puis les gestes à faire avant la date
  (groupes, exportation, contacts, Pages et outils par précaution).

👉 **Ouvrir le guide :** https://www.artemis-ia.app/guide-profils-facebook
